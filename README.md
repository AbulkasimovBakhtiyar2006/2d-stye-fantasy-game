# 2d-stye-fantasy-game

Simple starter structure for a browser-based 2D town quest game.

## Run

Open `/home/runner/work/2d-stye-fantasy-game/2d-stye-fantasy-game/index.html` in a browser,
or run a local static server from the repository root:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Move: **Arrow keys** or **WASD**
- Interact: **E**

## Gameplay

Wander around the town map, find quest markers, and complete quests in order:

1. Talk to the town elder (`N`)
2. Check the quest board (`B`)
3. Visit the shrine (`S`)
